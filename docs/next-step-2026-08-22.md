## Run this

```
cd ~/bc-wildlife-dashcam
rm -f ~/calibration_photos/photo*.jpg   # clear anything stale first
nohup python3 scripts/capture_calibration_photos.py > ~/capture_log.txt 2>&1 &
disown
```

Confirm it actually started before walking away:
```
sleep 6 && cat ~/capture_log.txt
```

**Do not start this until the checkerboard is actually being held up** —
it can't be paused once running short of killing it
(`pkill -f capture_calibration_photos.py`), and a run with nobody holding
the board just makes junk frames to clean up again.

Tell whoever's holding the board: listen for the buzzer, not the screen —
one beep = countdown tick, two quick beeps = photo saved, reposition now.
20 photos, ~4s apart, done in under 2 minutes.
