# BC Wildlife-Aware Dashcam System

Real-time multi-class detection of wildlife (by species), pedestrians (adult/child), 
and vehicles on embedded hardware with driver warning output. No internet required.

## Hardware
- Raspberry Pi 4
- Google Coral USB Accelerator
- Arducam 5MP OV5647 Motorized IR-CUT
- u-blox NEO-M8N GPS module
- 128x64 OLED display (SSD1306)
- RGB LED bar + active piezo buzzer
- Powered USB 3.0 hub
- MicroSD 128GB High Endurance
